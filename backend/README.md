# alphaMobile relay

Standalone Python 3.11+ package providing the phone HTTP API, authenticated MCP endpoint, SQLite state, local-only provisioning CLI and private APK feed. No language model or GPU is required.

Install with `python -m pip install ./backend` from the repository, or install the wheel from Releases. Run `alphamobile --help`. The Linux installer in `scripts/install-relay.py` also generates private configuration and an optional systemd user service.

Full installation, agent setup and operational documentation: https://github.com/xak1234/alphaMobile/tree/main/docs
