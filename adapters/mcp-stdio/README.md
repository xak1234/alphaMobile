# alphaMobile stdio MCP bridge

Install this independently on the computer running your desktop MCP client; the relay package is not required on that computer.

```bash
python3 -m venv .venv-mcp
.venv-mcp/bin/python -m pip install ./adapters/mcp-stdio
.venv-mcp/bin/alphamobile-mcp --connection /absolute/path/agent.connection.json
```

The connection file is generated by `alphamobile agent NAME --url URL --output FILE` on the relay host and transferred privately to this computer. It contains the agent's token. The bridge accepts HTTPS, with HTTP allowed only on loopback, forwards MCP initialization instructions and tools, and maintains agent presence while the client keeps it running. It does not invoke a model or wake a sleeping client.

Do not type into its stdio protocol manually. Configure it as an MCP server in your client. See https://github.com/xak1234/alphaMobile/blob/main/docs/MCP.md for exact configuration and agent lifecycle requirements.
